# Pushbutton_buzzer_LED_lightchanging

In this project there are two pushbuttons, the pushbutton on the left of the LED makes the LED brighter every time it is pressed or held. The pushbutton on the right of the LED dims the light every time it is pressed or held. If the LED has reached full brightness or is fully dimmed AND the user is still holding onto one of the buttons, the buzzer will buzz.
